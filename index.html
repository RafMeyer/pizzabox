PizzaBox

A tiny experimental desktop browser with tabs, navigation, a custom User-Agent and a deliberately simple interface.

Real tabs

Each tab uses its own Electron WebContentsView and keeps its own navigation history.

Small UI

Back, forward, reload, home, address bar, tab creation and tab closing.

PizzaBox User-Agent

PizzaBox carries its own product token so UA detectors can identify it.
